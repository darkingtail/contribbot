## 记录约定

发生实质进展、验证结果、阻塞变化或用户决定时及时落盘。
每日检查没有发现可核实的新进展时，简短记录这一事实与尚待处理的下一步，
不为了写日报重复测试、重复派工或制造任务。
无法读取某个任务、工具或运行环境时注明不可核实，不能据此判断没有进展。
漏跑日期不自动补造记录；确需回顾时标明回顾时间和原始证据日期。

每份记录包含：

| 内容 | 要求 | 备注 |
| --- | --- | --- |
| 总体判断 | 一句话说明正在做什么、处在哪个环节 | 不用没有依据的完成百分比 |
| 三段现状 | 前面发现任务、中间执行任务、后面交付与沉淀 | 区分已设计、已实现、已验证和未完成 |
