直接指定自托管 GitLab 等实例。Claude 建议仅在 Agent 层增加可重复的严格
`--repo-json`，保留公共 GitHub 的简写/URL 便利形式，不改 MCP、config.yaml、存储或远端
平台能力；位置参数与 JSON 参数并用时建议按完整身份去重合并。该入口是新的用户可见 CLI
表面，是否纳入本轮及合并语义需用户决定，业务代码尚未修改。
